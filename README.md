# Chessfall Ascension challenges

Link-preview pages for the Chessfall Ascension web challenges: each
`c/<id>.html` shows the puzzle's picture when its link is shared, then opens
the challenge to play in the browser.

Site: https://challenges.originsoftconsultancy.com

Generated by `tools/challenges/publish_previews.sh` in the game's repository.

Hosting: AWS S3 (bucket `originsoft-challenges`) behind CloudFront. Every
push to `master` uploads the files (`.github/workflows/deploy.yml`, signing
in to AWS through GitHub OIDC, no stored keys).
